# 로그아웃과 계정 데이터 분리

## `POST /api/auth/logout`

- 쿠키를 지우고, **그 쿠키 값도 서버에서 더는 받지 않아요.** 로그아웃한 쿠키를 다시 보내면 401 `LOGIN_REQUIRED` 예요.
- 로그아웃한 그 로그인만 끝나요. 같은 사람이 다른 기기에서 한 로그인은 그대로예요.
- 로그인하지 않은 채로 불러도 204 예요.

## 사용자별 응답은 저장하지 않아요

아래 응답에는 `Cache-Control: no-store` 와 `Vary: Cookie` 가 붙어요. 브라우저나 중간 서버가 앞사람의 응답을 다음 사람에게 보여주지 못해요.

- `/api/me/*`, `/api/auth/*` 전부 (로그인하지 않아서 401 인 응답도)
- 로그인 쿠키를 보낸 모든 `/api/*` 요청 (예: 커뮤니티 글 목록의 `liked_by_me`, `is_mine`)

로그인하지 않고 부른 공개 API(회사 정보, 뉴스 등)는 그대로예요.

## 프론트에서 같이 해 주세요

서버 응답은 저장되지 않지만, 프론트가 메모리에 들고 있는 값(React Query 캐시, localStorage)은 서버가 지울 수 없어요.
로그아웃하거나 다른 계정으로 로그인하면 사용자별 값(학습 기록, 잔액, 퀴즈 보상, 좋아요 표시)을 비워 주세요.
